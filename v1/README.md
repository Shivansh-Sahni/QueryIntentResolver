# Query Intent Resolver V1

Implementation-ready query routing from raw text.

## Frozen contract

```json
{
  "route": "short_circuit | medium | complex | llm_needed",
  "confidence": 0.91
}
```

Raw `query_text` is the only V1 model input. Persona, page, filters, prior messages, and session context are accepted only as decoupled future fields.

## One-command build

```bash
python -m pip install -r v1/requirements.txt
python v1/scripts/run_v1_pipeline.py
```

Generated artifacts are written under `v1/artifacts/`.

## Pipeline

1. Resolve contradictory historical route labels.
2. Export unresolved cases for review rather than guessing.
3. Freeze a deterministic, leak-free benchmark.
4. Train and calibrate the query-only LinearSVC baseline.
5. Run a deterministic diagnostic floor.
6. Evaluate accuracy, macro F1, false short-circuit rate, latency, and cost.
7. Compare all available real model runs.
8. Package the current leader behind a stable Python and HTTP interface.
9. Verify hashes, split integrity, and runtime schema.

## Model shootout

- LinearSVC: runs locally or in GitHub Actions.
- Deterministic rules: diagnostic floor only; never eligible to win.
- Anthony Qwen: GPU runner or included Colab workflow.
- Local zero-shot baseline: optional reproducible semantic baseline.
- API LLM baseline: optional, provider-neutral chat-completions runner.

Every model must predict the identical frozen benchmark. The benchmark may not be relabeled or replaced after model results are viewed.
